# AGENTS.md

## Sobre este repositorio

Este es un repositorio especial que gestiona el `README.md` de mi perfil de GitHub. El objetivo principal es mantenerlo actualizado y profesional.

## Directrices para agentes de IA

### 1. Tono y estilo
- **Tono**: Profesional, amigable y colaborativo.
- **Idioma**: Todas las comunicaciones y modificaciones deben ser en **español**.

### 2. Propósito del agente
- Ayudar a mantener y actualizar el contenido del `README.md`.
- Asegurarse de que el formato sea consistente y visualmente atractivo.
- Proporcionar sugerencias para mejorar la presentación de la información.

### 3. Modificaciones al `README.md`

#### Añadir un nuevo proyecto
Utiliza el siguiente formato para añadir un nuevo proyecto a la sección `Proyectos destacados`:

```markdown
- [Nombre del Proyecto](URL del proyecto): Breve descripción de tu rol o contribución.
```

#### Actualizar habilidades
Añade nuevas habilidades en la sección `Skills` manteniendo el formato existente.

### 4. Verificaciones
- Antes de finalizar, asegúrate de que todos los enlaces funcionen correctamente.
- Verifica que el formato del `README.md` no se haya roto.
- Confirma que los cambios se alinean con mi perfil profesional.

Gracias por tu ayuda.
